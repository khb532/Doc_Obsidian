# CoD 탄도 시스템 포트폴리오 기술 포인트

> 작성일: 2026년 04월 17일  
> 유형: 인사이트

---

## 배경

언리얼 엔진 CoD 브랜치에서 라이플탄 탄도 시스템 구현 중, 프로파일링 그래프로 속도 곡선을 분석하다가 현재 설계의 확장 가능성과 포트폴리오 기술 방향을 정리한 내용.

---

## 내용

### 현재 구현
- Semi-implicit Euler 적분 (속도 → 위치 순차 적분)
- 중력 + 항력(V²) 물리 모델
- `ComputeAcceleration` 가상함수로 탄종별 가속도 분리 설계
- 실측 파라미터 적용 (5.56mm: mass=4g, Cd=0.3, A=0.243cm², 종단속도 ~93m/s 수식 일치)
- 프로파일링 위젯으로 속도 그래프 실시간 시각화

### 확장 가능성 (포트폴리오 기술)
- **RK4 도입**: Base의 적분 로직만 교체하면 되는 구조 — `ComputeAcceleration` 추상화 덕분에 비침투적 전환 가능
- **마그누스 효과 / 바람**: `ComputeAcceleration` 반환값에 외력 합산만으로 추가 가능
- **로켓탄 추진체**: 추력(Thrust)을 `ComputeAcceleration`에 합산, BurnTime 기반 추진 종료 후 자동으로 라이플탄과 동일한 탄도로 전환

### 탄종별 그래프 비교
- 라이플탄: 감속 + 자유낙하 → U자 곡선
- 로켓탄: 가속(추진) → 최고속도 → 감속+낙하 → 역U자 또는 상승 후 U자
- 두 그래프 병렬 비교가 포트폴리오 시각 자료로 유효
