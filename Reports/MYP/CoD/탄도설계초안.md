# 탄도 시뮬레이션 설계 초안

> 작성일: 2026-04-11  
> 브랜치: CoD

---

## 물리 모델

### 총구 이탈 순간 — 초기속도 직접 지정

```
V₀ = MuzzleVelocity * WeaponMultiplier    ← 탄종 스펙 × 총기 보정치
```

총열 내부 시뮬레이션(화약 폭발력, 총열 체류 시간)은 불필요한 복잡도로 제외.  
총구초속 하나로 대체. 단, 무기(Weapon)가 스폰 직후 `WeaponMultiplier`를 전달하여  
같은 탄종이라도 총기 스펙(총열 길이, 화력)에 따라 초속이 달라질 수 있도록 설계.

### 비행 중 매 프레임

```
F_gravity = Mass * G                          (아래 방향, G = 980 cm/s²)
F_drag    = -0.5 * ρ * Cd * A * V²           (진행 반대 방향)

a = (F_gravity + F_drag) / Mass

Velocity += a * dt
Position += Velocity * dt
```

**핵심: Mass가 분모에 들어가기 때문에**
- 라이플탄 (가벼움) → 항력 영향 큼 → 빠르게 감속·낙하
- 로켓탄 (무거움) → 관성 유지 → 완만한 탄도, 추력으로 보상

### 탄종별 기준 수치

| 탄종 | MuzzleVelocity | Mass | Cd | CrossSectionArea |
|------|---------------|------|----|-----------------|
| 라이플 (5.56mm) | 92000 cm/s | 4 g | 0.30 | 0.5 cm² |
| 재블린 로켓 | 18000 cm/s | 8500 g | 0.50 | 30 cm² |

## 데이터 흐름

```
AShooterWeapon
  └── WeaponMultiplier (float)  — 총기별 초속 보정치 (기본 1.0)
        │
        │ SpawnActor 직후 InitWithBulletData() 호출 시 전달
        ▼
ABulletBase
  ├── Mass (g)
  ├── MuzzleVelocity (cm/s)   — 탄종 고유 총구초속
  ├── Cd                      — 항력계수
  └── CrossSectionArea (cm²)
        │
        │ BeginPlay에서 컴포넌트에 전달
        ▼
UCODProjMove_Base
  ├── Velocity = ForwardVector * (MuzzleVelocity * WeaponMultiplier)
  ├── TObjectPtr<USceneComponent> UpdatedComponent  — GC 안전 캐싱
  └── 매 프레임 ComputeAcceleration() 호출
        │
        ├── UCODProjMove_Rifle  : 중력 + 항력(DragScale 튜닝 포함)
        └── UCODProjMove_Rocket : 중력 + 항력 + 추력(ThrustDuration 동안)
```

## 클래스 구조

### ABulletBase

```cpp
UCLASS(Abstract)
class ABulletBase : public AActor
{
    // 탄도 물리 파라미터
    UPROPERTY(EditDefaultsOnly, Category="Ballistics")
    float Mass = 1.0f;              // 질량 (g)

    UPROPERTY(EditDefaultsOnly, Category="Ballistics")
    float MuzzleVelocity = 90000.f; // 총구초속 (cm/s)

    UPROPERTY(EditDefaultsOnly, Category="Ballistics")
    float Cd = 0.3f;                // 항력계수

    UPROPERTY(EditDefaultsOnly, Category="Ballistics")
    float CrossSectionArea = 1.0f;  // 단면적 (cm²)

    // 데미지
    UPROPERTY(EditDefaultsOnly, Category="Damage")
    float HitDamage = 25.f;

    UPROPERTY(EditDefaultsOnly, Category="Damage")
    float PhysicsForce = 100.f;

    UPROPERTY(EditDefaultsOnly, Category="Damage")
    TSubclassOf<UDamageType> HitDamageType;

    // 파괴
    UPROPERTY(EditDefaultsOnly, Category="Destruction")
    float DeferredDestructionTime = 5.f;

    // 공통 인터페이스
    virtual void OnBulletHit(const FHitResult& Hit);
    void ApplyDamage(AActor* HitActor, const FVector& HitLocation, const FVector& HitDirection);

    UFUNCTION(BlueprintImplementableEvent)
    void BP_OnBulletHit(const FHitResult& Hit);
};
```

### UCODProjMove_Base

```cpp
UCLASS(Abstract)
class UCODProjMove_Base : public UActorComponent
{
    // ABulletBase로부터 주입받는 탄도 데이터
    float Mass;
    float Cd;
    float CrossSectionArea;

    // 내부 상태
    FVector Velocity = FVector::ZeroVector;
    TArray<FVector> TrajectoryPoints;   // 궤적 누적 (디버그용)
    TObjectPtr<USceneComponent> UpdatedComponent;

    // 초기화 — AShooterWeapon이 SpawnActor 직후 호출
    // WeaponMultiplier: 총기별 초속 보정치 (기본 1.0, 총열 길이·화력 반영)
    void InitWithBulletData(float InMass, float InMuzzleVelocity, float InCd, float InArea, float WeaponMultiplier = 1.0f);

    // Tick 공통 흐름 (고정)
    virtual void TickComponent(...) override;

    // 자식이 재정의하는 가속도 계산
    virtual FVector ComputeAcceleration(float DeltaTime);

    // 궤적 디버그 드로우
    void DrawTrajectory();

    UPROPERTY(BlueprintAssignable)
    FOnHitDelegate OnHitDelegate;
};
```

**TickComponent 공통 흐름 (베이스에 고정):**
```
1. 유효성 검사
2. Acceleration = ComputeAcceleration(dt)    ← 자식이 재정의
3. Velocity += Acceleration * dt
4. Delta = Velocity * dt
5. SweepSingleByChannel
6. Hit   → OnHitDelegate.Broadcast + 궤적 저장 후 Tick 중단
   NoHit → SetWorldLocation + SetWorldRotation + TrajectoryPoints 누적
7. DrawTrajectory()
```

### UCODProjMove_Rifle

```cpp
class UCODProjMove_Rifle : public UCODProjMove_Base
{
    // 공기밀도 (해수면 기준)
    UPROPERTY(EditAnywhere, Category="Ballistics")
    float AirDensity = 0.001225f;   // g/cm³

    // V² 스케일 문제 보정용 튜닝 변수
    // V=90000 cm/s → V²=8.1e9 → 그대로 쓰면 수치 폭발
    // DragScale로 게임적 사거리 밸런스 조정
    UPROPERTY(EditAnywhere, Category="Ballistics")
    float DragScale = 0.0001f;

    // 가속도 = 중력 + 항력
    // F_drag = -0.5 * ρ * Cd * A * V²  (속도 반대 방향)
    // a_drag = (F_drag / Mass) * DragScale
    virtual FVector ComputeAcceleration(float DeltaTime) override;
};
```

### UCODProjMove_Rocket

```cpp
class UCODProjMove_Rocket : public UCODProjMove_Base
{
    UPROPERTY(EditAnywhere, Category="Rocket")
    float ThrustForce = 80000.f;    // 추력 (cm 단위계, DragScale과 동일한 스케일 고려)
    
    // 로켓도 항력 적용 — DragScale은 베이스에서 상속
    // ThrustForce가 충분히 크면 항력+중력을 상쇄하고 가속

    UPROPERTY(EditAnywhere, Category="Rocket")
    float ThrustDuration = 1.5f;    // 추력 지속 시간 (s)

    float ElapsedTime = 0.f;

    // 가속도 = 중력 + 항력 + 추력(ThrustDuration 동안 ForwardVector 방향)
    virtual FVector ComputeAcceleration(float DeltaTime) override;
};
```

## 구현 순서

```
[1] ABulletBase
    - Mass, MuzzleVelocity, Cd, CrossSectionArea 정의
    - BeginPlay에서 컴포넌트에 InitWithBulletData() 호출
    - OnBulletHit(), ApplyDamage() 공통 구현

[2] UCODProjMove_Base 리팩토링 (기존 COD_ProjectileMovementComponent 기반)
    - InitWithBulletData() 수신 → Velocity = ForwardVector * MuzzleVelocity
    - ComputeAcceleration() 가상함수화
    - 궤적 TArray 누적 + DrawDebugLine 체인

[3] UCODProjMove_Rifle
    - ComputeAcceleration() = 중력 + 항력

[4] UCODProjMove_Rocket
    - ComputeAcceleration() = 중력 + 항력 + 추력(ThrustDuration 동안)

[5] ASmallCaliber : ABulletBase
    - 라이플 파라미터 세팅, Rifle 컴포넌트 장착

[6] ARocketBullet : ABulletBase
    - 로켓 파라미터 세팅, Rocket 컴포넌트 장착
    - 폭발 로직 추가
```
